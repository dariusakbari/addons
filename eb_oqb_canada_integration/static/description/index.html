Quickbooks Canada Online Integration

This module offers a comprehensive and seamless integration between Odoo and Quickbooks, providing a reliable solution for real-time synchronization of essential financial and business records. It is designed to streamline accounting operations by connecting core Odoo modules like Currency, Account Tax, Chart of Accounts, Customer, Product, Sale Orders, Invoices, Credit Notes, Customer Payment, Vendor, Purchase Order, Bills, Refunds, Vendor Payment, Payment Term, Payment Method, Employee, Department directly with Quickbooks.

The integration ensures accurate mapping and smooth data flow between both platforms. It supports bidirectional syncing for contacts, invoices, and payments, automatic tax and account code matching, and instant updates across both systems — reducing manual effort and eliminating data discrepancies. Whether you’re managing customer invoices, vendor bills, sales quotes, or employee records, this connector intelligently handles the exchange of critical financial data with minimal configuration.

This module is ideal for businesses seeking real-time visibility, enhanced financial control, and a fully automated accounting workflow between Odoo and Quickbook. It promotes data consistency, simplifies reconciliation, and ensures compliance with accounting best practices — all while keeping your financial operations in sync and under control.

Create a QuickBooks Developer account and set up a workspace.

Go to https://developer.intuit.com/

Click Sign Up (or Sign In if you already have an Intuit account).

After signing in, create a workspace.

Create a New App

Select a Workspace, then click the “+” icon to start creating your app.

App Created — Access Credentials

After the app is created, click on the app from your App dashboard.

Go to the Keys & Credentials tab.

Here you will find: Client ID, Client Secret.

Set Redirect URIs

On the Keys & Credentials tab --> Settings --> Redirect URIs

Use the Credentials in Your Integration

Use Client ID, Client Secret, and Redirect URI to initiate the OAuth 2.0 flow from Odoo.

Click the “Generate Authorization URL” button.

Select the QuickBooks company you want to authorize.

After selecting the company, you’ll be redirected to your configured Redirect URI

The authorization code will be included in the URL (e.g., ?code=abc123...).

Copy this code, as you’ll need it to exchange for access and refresh tokens.

After generating the authorization code, paste it into the “Authorization Code” field.

After generating the authorization code, click the “Generate Access Token” button to create your Access Token and Refresh Token.

In the second configuration step, enter the following details:

Company ID: (from QuickBooks) API Base URL: e.g., Sandbox or Production endpoint QuickBooks Time Zone: QuickBooks Version: e.g., 73 Odoo Company: Select the corresponding company Pagination Size: Set the preferred size

When the user clicks on “QuickBooks to Odoo”, all Tax from QuickBooks are fetched and synced into Odoo.

What data can be synced between Odoo and Quickbooks?

The app supports syncing of Currency, Account Tax, Chart of Accounts, Customer, Product, Sale Orders, Invoices, Credit Notes, Customer Payment, Vendor, Purchase Order, Bills, Refunds, Vendor Payment, Payment Term, Payment Method, Employee, Department.

How can I sync records between Odoo and QuickBooks?

Manual actions, Scheduled sync (via cron jobs), List view actions, Form view button, Import wizard.

Can I sync selected records only?

Yes, you can manually sync individual records or use scheduled sync for batch operations.

Is the synchronization one-way or two-way?

The integration supports both import from and export to Quickbooks, depending on the model and settings.

Can I schedule automatic sync jobs?

Yes, you can configure scheduled actions for automated import/export between Odoo and Quickbooks.

Is there a log history for synchronization actions?

Yes, all sync operations are logged with success and error messages for easy tracking.

Is this integration only for QuickBooks Online Canada?

It does not support other regions like USA, UK, or Australia. However, we offer a separate module for QuickBooks Online – USA.

Does this module support refund and credit note functionality?

Yes, this integration fully supports refund and credit note synchronization between Odoo and QuickBooks, ensuring that all financial adjustments are accurately reflected on both sides.
